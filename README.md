## What's inside

- `gemini-test.ipynb`: a Jupyter notebook that connects to the Google Gemini API and gets a reply from the model

## Tools I use

- Python
- Jupyter Notebook
- Google Gemini API (`google-genai`)
- python-dotenv, to keep my API key private
- Git and GitHub

## How to run

1. Install the libraries: `pip install google-genai python-dotenv`
2. Create a file named `.env` and add: `GEMINI_API_KEY=your-key-here`
3. Open `gemini-test.ipynb` and run the cells

My API key is stored in `.env` and is never uploaded to GITHUB.
